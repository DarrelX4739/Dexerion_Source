Extensions

Install Chrome-compatible extensions from the Web Store, or load your own from a folder or package.

Chrome Web Store

On any Web Store item page Dexerion offers the install automatically — or paste the item URL here.

Developer mode

Load an unpacked extension from a folder or .zip/.crx file (manifest.json + background, content scripts, popup). Folders load in place — edit the code, hit Reload, and the change goes live. Clicking the toolbar icon opens the popup, or quick actions when the extension has none.
